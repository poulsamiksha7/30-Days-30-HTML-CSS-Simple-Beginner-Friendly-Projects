## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/poulsamiksha7/30-Days-30-HTML-CSS-Simple-Beginner-Friendly-Projects.git
   cd 30-Days-30-HTML-CSS-Simple-Beginner-Friendly-Projects
   ```

2.  Open the project directories to view and edit the HTML and CSS files.

## Usage

Each project is contained in its own directory. Simply open the `index.html` file in your browser to view the project. You can then modify the HTML and CSS files to experiment and learn.
